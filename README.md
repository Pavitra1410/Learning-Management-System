# Learning-Management-System

A modern, high-performance Learning Management System (LMS) web application.

## 🚀 Features

- **Dynamic Interactive UI**: Built with React 19, Vite, Tailwind CSS, and Lucide React icons.
- **Fast Build System**: Zero-config lightning-fast builds powered by Vite.
- **Comprehensive Dashboard & Course Modules**: Real-time progress tracking, video learning streams, interactive quizzes, and course analytics.
- **Clean Component Architecture**: Modular layout, custom dark mode styling, and accessible responsive design.

## 🛠️ Tech Stack

- **Frontend**: React 19, React Router v7, Tailwind CSS, Lucide Icons
- **Build Tool**: Vite 8
- **Linter**: Oxlint

## 🚦 Getting Started

### Prerequisites
- Node.js (v18+)
- npm / pnpm / yarn

### Installation

1. Clone the repository:
```bash
git clone https://github.com/Pavitra1410/Learning-Management-System.git
cd Learning-Management-System/client
```

2. Install dependencies:
```bash
npm install
```

3. Run the development server:
```bash
npm run dev
```

4. Build for production:
```bash
npm run build
```

## 📦 Deployment

The application is pre-configured for seamless deployment to platforms like **Vercel**, **Netlify**, or **Cloudflare Pages**:
- **Root Directory**: `client`
- **Build Command**: `npm run build`
- **Output Directory**: `dist`
